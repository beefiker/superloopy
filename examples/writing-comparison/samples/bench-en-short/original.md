Hello! API v1 stops accepting new requests after 2026-09-30, so please migrate before then. Authentication and the basic response structure are unchanged: keep your Authorization header and add X-API-Version: 2, since omitting it may fall back to v1. Don't rename request fields; compare responses against https://docs.example.com/api/v2. Apply in development, then staging, then production, confirming proxies and SDKs forward the header, and record the apply date and verification result per service. Hope this helps!
