# Proposal: shared design tool licence

**Problem:** design files live across a shared folder and three personal accounts. The current file is whichever copy someone last put back.

**Proposal:** one paid workspace, three months, then decide.

## Benefits

- One current file per project, with version history that survives forgetfulness.
- Comments attached to the file, not buried in a chat thread.
- Handover is a link, not a folder tour.

## Costs

| Item | Monthly cost | Who |
| --- | --- | --- |
| Design workspace | $29 per month | 8 people |
| Extra viewer seats | Included | Support and operations |
| Storage above 100 GB | $6 per month | Only if we exceed it |

## Risks

**Half-migrated files.** We could spend the trial moving work across and then decide the tool does not fit.

**Containment.** Only new projects start in the workspace during the trial. Existing folders do not move.

## Decision

Keep the workspace and migrate what remains, or do not renew the contract and return to the existing shared folder approach.
