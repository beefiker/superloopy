# Proposal: shared design tool licence

Design work is currently spread across a shared folder and three personal accounts, so the current file is whichever copy somebody last put back. This proposal moves the team onto one paid workspace for three months, then decides.

## Benefits

- One current file per project, with version history that does not depend on anyone remembering to copy it.
- Comments stay attached to the file instead of living in a chat thread.
- Handing a project to a new person is a link rather than a folder tour.

## Costs

| Item | Monthly cost | Who |
| --- | --- | --- |
| Design workspace | $29 per month | 8 people |
| Extra viewer seats | Included | Support and operations |
| Storage above 100 GB | $6 per month | Only if we exceed it |

## Risks

The main risk is spending three months moving files and then concluding the tool does not fit, leaving the work half migrated. To contain that, only new projects start in the workspace during the trial and existing folders stay where they are.

## Decision

After three months we either keep the workspace and migrate the remaining folders, or we do not renew the contract and return to the existing shared folder approach.
