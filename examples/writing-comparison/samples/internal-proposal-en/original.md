# Proposal: shared design tool licence

At the moment the design work is spread across a shared folder and three personal accounts, which means the current file is whichever copy somebody last remembered to put back. What this proposal suggests is moving the team onto a single paid workspace for a trial of three months and then making a decision.

## Benefits

- One current file for each project, with a version history that does not depend on anybody remembering to copy anything.
- Comments stay attached to the file itself instead of living somewhere in a chat thread.
- Handing a project to a new person becomes a link rather than a guided tour of a folder.

## Costs

| Item | Monthly cost | Who |
| --- | --- | --- |
| Design workspace | $29 per month | 8 people |
| Extra viewer seats | Included | Support and operations |
| Storage above 100 GB | $6 per month | Only if we exceed it |

## Risks

The main risk here is that we spend three months moving files across and then conclude the tool does not fit, which would leave the work half migrated. To keep that contained, only new projects would start in the workspace during the trial, and existing folders would stay exactly where they are.

## Decision

At the end of three months we either keep the workspace and migrate the folders that remain, or we do not renew the contract and return to the existing shared folder approach.
