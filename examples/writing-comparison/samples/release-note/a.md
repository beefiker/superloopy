# 8월 20일 배포 안내

2026-08-20 오후 3시에 웹 서비스를 배포합니다. 이번에는 운영 중 발견한 검색 결과 정렬 문제와 목록 화면 표시 오류를 고칩니다. 배포 중에는 최대 5분 동안 저장이 느려질 수 있습니다. 이미 작성한 내용은 자동 저장됩니다. 중요한 내용을 입력하기 전에는 현재 내용을 한 번 확인해 주세요.

## 변경 사항

- 검색 필터를 두 개 이상 선택했을 때 결과가 비어 보이던 문제를 고칩니다.
- 목록에서 담당자 이름이 길면 날짜와 겹치던 문제를 고칩니다.
- 알림 설정을 저장한 뒤 이전 화면으로 돌아갈 때 선택값이 사라질 수 있던 문제를 고칩니다.

## 확인 요청

배포 뒤에는 운영팀이 검색 필터, 목록 화면, 알림 설정을 순서대로 확인하고 각 기능을 테스트 계정과 일반 권한 계정에서 한 번씩 점검합니다. 오류를 발견하면 발생한 시각과 사용한 브라우저, 화면 경로를 적어 운영 채널에 남겨 주세요. 배포가 끝난 뒤 따로 공지가 없으면 같은 날 오후 4시까지 모니터링합니다. 점검 중 저장이 늦어지면 입력을 반복하지 말고 저장 상태가 바뀌는지 먼저 확인합니다. 같은 문제가 두 번 나오면 화면 캡처도 남깁니다. 점검 결과는 기능별로 정상, 재현 필요, 조치 중으로 표시해 다음 교대자에게 전달합니다. 조치 중인 항목은 담당자와 다음 확인 시각도 적습니다.

## 문제 발생 시

같은 오류가 두 번 확인되면 배포 담당자는 추가 배포를 멈추고 직전 버전으로 되돌릴지 운영팀과 판단합니다. 판단 결과와 고객 공지가 필요한지는 운영 채널에 남깁니다.
