# 8월 20일 배포 안내

**일정:** 2026-08-20 오후 3시

웹 서비스를 배포합니다. 검색 정렬과 목록 표시 오류를 수정합니다. 배포 중 저장 기능은 최대 5분 느려질 수 있습니다. 작성 내용은 자동 저장되지만, 중요한 입력 전에는 저장 상태를 확인해 주세요.

## 변경 사항

- [검색] 필터를 두 개 이상 선택하면 결과가 비어 보이던 문제 수정
- [목록] 담당자 이름이 길 때 날짜가 겹치던 문제 수정
- [알림] 설정 저장 후 이전 화면으로 돌아가면 선택값이 사라질 수 있던 문제 수정

## 운영팀 확인

1. 검색 필터를 테스트 계정과 일반 권한 계정에서 각각 확인합니다.
2. 목록 화면과 알림 설정을 같은 방식으로 확인합니다.
3. 오류가 있으면 발생 시각, 브라우저, 화면 경로를 운영 채널에 남깁니다.

별도 공지가 없으면 같은 날 오후 4시까지 모니터링합니다. 저장이 늦어지면 입력을 반복하지 말고 저장 상태 변화를 먼저 봅니다. 같은 문제가 두 번 나오면 화면 캡처도 운영 채널에 남깁니다. 점검 결과는 기능별로 정상, 재현 필요, 조치 중으로 표시해 다음 교대자에게 전달합니다.

**문제 발생 시:** 같은 오류가 두 번 확인되면 추가 배포를 멈춥니다. 조치 중인 항목에는 담당자와 다음 확인 시각을 적습니다. 직전 버전으로 되돌릴지는 운영팀과 판단하고, 결과와 고객 공지 필요 여부를 운영 채널에 남깁니다.
