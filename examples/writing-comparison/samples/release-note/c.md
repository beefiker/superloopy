- 알림 설정을 저장한 뒤 이전 화면으로 돌아갈 때 선택값이 사라질 수 있던 문제를 수정합니다.

## 확인 요청

운영팀은 검색 필터, 목록 화면, 알림 설정을 테스트 계정과 일반 권한 계정에서 확인합니다. 오류가 있으면 발생 시각, 브라우저, 화면 경로를 운영 채널에 남겨 주세요. 별도 공지가 없으면 같은 날 오후 4시까지 모니터링합니다. 저장이 늦어지면 입력을 반복하지 말고 저장 상태 변화를 먼저 확인합니다. 같은 문제가 두 번 나오면 화면 캡처도 남깁니다. 점검 결과는 기능별로 정상, 재현 필요, 조치 중으로 표시해 다음 교대자에게 전달합니다.

같은 오류가 두 번 확인되면 추가 배포를 멈춥니다. 조치 중인 항목에는 담당자와 다음 확인 시각을 적습니다. 직전 버전으로 되돌릴지는 운영팀과 판단하고, 결과와 고객 공지 필요 여부를 운영 채널에 남깁니다.
