# 8월 20일 배포 안내

2026-08-20 오후 3시에 웹 서비스 배포를 진행합니다. 이번 배포는 운영 중 발견된 검색 결과 정렬 문제와 목록 화면의 표시 오류를 수정하는 작업입니다. 배포 시간에는 최대 5분 동안 저장 기능이 느려질 수 있습니다. 이미 작성한 내용은 자동 저장되지만, 중요한 입력을 시작하기 전에는 현재 내용을 한 번 확인해 주세요.

## 변경 사항

- 검색 필터를 두 개 이상 선택했을 때 결과가 비어 보이던 문제를 수정합니다.
- 목록에서 담당자 이름이 길면 날짜가 겹치던 표시 문제를 수정합니다.
- 알림 설정을 저장한 뒤 이전 화면으로 돌아갈 때 선택값이 사라질 수 있던 문제를 수정합니다.

## 확인 요청

배포 후 운영팀은 검색 필터, 목록 화면, 알림 설정을 차례로 확인합니다. 각 기능은 테스트 계정과 일반 권한 계정에서 한 번씩 점검합니다. 오류가 보이면 발생 시각, 사용한 브라우저, 화면 경로를 함께 기록해 운영 채널에 남겨 주세요. 배포가 끝난 뒤 별도 공지가 없으면 같은 날 오후 4시까지 모니터링을 이어갑니다. 점검 중 저장 지연이 발생하면 입력을 반복하지 말고 저장 상태가 바뀌는지 먼저 확인합니다. 같은 문제가 두 번 나오면 화면 캡처도 함께 남깁니다. 점검 결과는 기능별로 정상, 재현 필요, 조치 중으로 표시해 다음 교대자에게 전달합니다. 조치 중인 항목은 담당자와 다음 확인 시각도 적습니다.

## 문제 발생 시

같은 오류가 두 번 확인되면 배포 담당자는 추가 배포를 멈추고 직전 버전으로 되돌릴지 운영팀과 판단합니다. 판단 결과와 고객 공지 필요 여부는 운영 채널에 남깁니다.
